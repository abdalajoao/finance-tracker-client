# 💰 Finance Tracker

A full-stack personal finance management application built to help users track their income, expenses, categories, and overall financial activity.

The project was developed as a full-stack application with a React frontend, Node.js/Express backend, MongoDB database, and JWT-based authentication.

---

## 🚀 Live Demo

🔗 Frontend: https://finance-tracker-client-ndkx.vercel.app/login

🔗 Backend API: https://finance-tracker-server-w158.onrender.com/


## ✨ Features

- 🔐 User registration and authentication
- 🔑 JWT-based authentication
- 💰 Track income and expenses
- 📊 Financial dashboard
- 🧾 Create, edit and delete transactions
- 🏷️ Transaction categories
- 👤 User-specific data
- 🔒 Protected API routes
- 📱 Responsive interface
- ☁️ Production deployment
